# GlowSkin-Advanced-WEB-Project

## About the Project
A web application for skin analysis, case management, and doctor dashboard system.

## Features
- Upload skin images
- AI-based analysis (frontend simulation)
- Doctor case review (approve / reject)
- Dashboard statistics
- Routine builder and display

## Tech Stack
- React.js
- React Router
- CSS Variables

## Getting Started
In the project directory, run:

npm install
npm start

Open http://localhost:3000
